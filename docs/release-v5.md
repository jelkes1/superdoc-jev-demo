## Measured result

On the bundled fictional agreement, five repetitions per model produced the same five verified edits in all 15 workflows. Compared with GPT-5.4 mini + SuperDoc, Jev + SuperDoc used **1.176 seconds less median active processing (24.4%)** and **$0.000732288 less mean estimated model spend per run (82.4%)**. Reported cached-input discounts are included. At 10,000 equivalent runs, the model-spend projection is **$7.32 less**.

These are workload-specific document-execution results. Model spend excludes SuperDoc licensing, hosting and human review. The separate recorded hosted run is retained in the evidence bundle and is not substituted for the repeated benchmark.
